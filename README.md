# lingualink

Маркетплейс контента для изучения языков.

Платформа объединяет идеи **Duolingo** (практика, упражнения, прогресс) и **Udemy** (маркетплейс курсов от креаторов).

---

## Идея проекта

Пользователи могут:

* изучать языки через курсы и упражнения
* отслеживать свой прогресс
* общаться с другими пользователями
* практиковаться через чат с AI
* использовать встроенный переводчик
* читать книги по уровням языка

Креаторы могут публиковать свои курсы и зарабатывать рейтинг.
Администраторы модерируют контент и пользователей.

### AI Chat

В разделе «Чат» откройте «Языковая практика с ИИ», выберите язык и отправьте сообщение. Для продолжения разговора модель получает последние шесть пар реплик. Диалог хранится в открытой странице.

---

### Translator

В разделе «Ресурсы» откройте «Переводчик», выберите язык перевода и введите текст. Исходный язык определяется автоматически.

### Интеграции

Чат и переводчик используют DeepSeek через OpenRouter. Запросы к провайдеру отправляет бэкенд.

1. При первом запуске создайте в корне проекта файл `.env` из `.env.example`, если его ещё нет.
2. Вставьте ключ в строку `OPENROUTER_API_KEY=`. Переменная `OPENROUTER_MODEL` задаёт модель. По умолчанию используется `deepseek/deepseek-v3.2`.
3. Запустите проект командой `docker compose up -d --build`. При замене ключа в работающем проекте достаточно `docker compose up -d backend`.

При запуске через Maven из каталога `backend` профиль `local` также читает корневой `.env`. После изменения файла перезапустите бэкенд.
